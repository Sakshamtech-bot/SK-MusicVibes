# 🎵 SK MusicVibes

A modern and responsive music-themed single-page website created as part of the **"Ship Your First Web Page"** web development task.

## 🎧 About the Project

SK MusicVibes is a music discovery website where users can explore different music genres, playlists, artists, and discover music according to their mood.

## ✨ Features

- 🏠 Home section
- 🎵 Music genres
- 🎧 Playlist section
- 👨‍🎤 Artists section
- 🔍 Music search
- ▶️ Play/Pause buttons
- 🌙 Dark Mode
- 📱 Responsive design
- 🎨 Modern music-inspired UI
- 🌈 Animated-style music branding

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
